# cs193-system-overlay
System Overlay project for pc
Project goal:
Lightweight, customizable, system overlay that displays real time stats.

MVP Scope:
Transparent, always on top window
Live metric collecting using OSHI
Basic UI configuration panel to toggle metrics

Future Plans:
Drag and drop widget layout editor
Custom themes and transparency levels

Tech Stacks:
Language: Java
UI Framework: JavaFX / Swing
Telemetry Library: OSHI (System and Hardware Information)
Hotkey Hooking: JNativeHook
Data Storage: Local JSON configuration files
